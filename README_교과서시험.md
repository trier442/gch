# 과천외고 교과서 전체 시험 (박시언교과서 시험범위)

- 출처: **박시언교과서 시험범위.pdf** 단독 (PDF 48쪽 / 교과서 38–85쪽)
- 전체 1070문항, 12개 영역
- 원문을 복사하여 배포하지 않으며 교과서 내용을 바탕으로 새 문제를 구성
- 유형: 객관식/단답형/OX, 해설 및 쪽수 표시
- GitHub 웹 페이지: /gch/textbook.html
- 학생 성적·오답: 기존 Supabase exam_results 및 교사용 teacher.html 연동
- 실전 시험은 종료 시 채점, 학습 모드는 즉시 해설 확인, 오답 재시험 지원
- 단답형 자동 채점은 단순 정규화 기반이므로 다양한 동의 표현은 교사가 확인 필요
- 새말, 품사 통용, 발음은 **첨부 교과서 분류·표기**를 기준으로 출제

## 파일
- textbook.html 학생용 새 탭
- textbook_q1.js ~ textbook_q12.js: 전체 문제은행 분할 스크립트
- textbook_questions.json: 교사가 수정할 수 있는 전체 JSON 문제 데이터 (배포에는 필수 아님)

## 설정
GitHub Pages의 main /(root) 배포가 활성화되어 있어야 공개 사이트 주소가 작동합니다.
시험 제출에 필요한 Supabase 연결은 gch의 config.js를 참조합니다.
